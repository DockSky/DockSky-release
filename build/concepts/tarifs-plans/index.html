Les testeurs invités reçoivent un code DSK-… et passent en Pro pendant la beta. Demande d'accès: docksky.fr/equipage ou formulaire contact.

Configuration dans Paramètres → Coffre / Machines / Journal. L'exécution via Cursor (synapse_exec) reste réservée au plan Pro (scope MCP).

L'interface est disponible en français, anglais, espagnol et allemand (Paramètres → Langue).
