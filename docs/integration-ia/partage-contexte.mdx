# Partage de contexte automatique

Plutôt que de copier-coller le contexte à chaque session, tu peux configurer ton IA pour qu'elle récupère ton contexte DockSky automatiquement à chaque conversation — sans aucune action de ta part.

---

## Comment ça fonctionne

Quand tu actives l'accès IA sur un projet, DockSky génère un **lien unique** vers le contexte de ce projet. Tu configures ton IA préférée pour qu'elle consulte ce lien à chaque début de conversation.

Le lien reste à jour automatiquement : quand tu modifies tes Facettes, l'IA dispose du nouveau contexte dès la prochaine conversation.

---

## Activer l'accès IA sur un projet

1. Ouvre ton projet (vue **Projets**)
2. Clique sur les paramètres du projet (icône ⚙️)
3. Active l'option **Accès IA**
4. Choisis le niveau d'accès :
   - **Lecture** — ton IA peut lire les Facettes (recommandé)
   - **Écriture** — ton IA peut aussi ajouter des notes
5. Copie le **lien de contexte** généré

---

## Configurer Claude

1. Va dans Claude → **Settings** → **Custom Instructions** (ou "Instructions système")
2. Ajoute une instruction du type :

```
Début de chaque conversation : consulte mon contexte de projet à l'adresse [LIEN DOCKSKY].
Base tes réponses sur ce contexte.
```

---

## Configurer ChatGPT (Custom GPT)

1. Crée un **Custom GPT** (assistant ChatGPT personnalisé) dans ChatGPT
2. Dans les instructions, ajoute le lien DockSky et demande à GPT de le consulter
3. Utilise ce GPT pour tes sessions liées à ce projet

---

## Révoquer l'accès

Si tu veux révoquer l'accès (bloquer le lien existant et en générer un nouveau) :

1. Ouvre les paramètres du projet
2. Clique sur **Révoquer l'accès**
3. Un nouveau lien est généré — l'ancien ne fonctionne plus

:::caution
Si tu as partagé ce lien avec quelqu'un ou configuré plusieurs outils avec, pense à mettre à jour chaque configuration après la révocation.
:::
