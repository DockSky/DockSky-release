# Partage de contexte avec l'IA

DockSky ne propose **pas** de lien public auto-mis à jour vers ton contexte projet. Le partage passe par des méthodes explicites que tu contrôles : copier-coller, packs **Contextes IA**, ou connexion **MCP**.

---

## Niveau d'accès IA par projet

Chaque projet a un réglage **Accès IA** (`NONE` / `READ` / `WRITE`) :

1. Ouvre ton projet (vue **Projets** → détail du projet)
2. Section **Accès IA** : choisis le niveau
 — - **NONE** — le projet est invisible pour le MCP (et filtré côté outils IA)
 — - **READ** — lecture seule (facettes, journal, roadmap…)
 — - **WRITE** — lecture + écriture (création/mise à jour d'entrées, selon permissions)

Ce réglage s'applique au **serveur MCP** et aux exports manuels : il ne génère pas d'URL publique.

---

## Méthode 1 : Copier le JSON (immédiat)

1. Vue **Facettes** ou **Contextes IA**
2. Sélectionne les notes pertinentes
3. Clique **Copier JSON**
4. Colle en début de conversation dans Claude, ChatGPT, etc.

→ Détail : [Utiliser DockSky avec ton IA](./configurer-son-llm) · [Contextes IA](./contextes-ia)

---

## Méthode 2 : Contextes IA (packs réutilisables)

Crée des groupes nommés (« Session backend », « Briefing client X ») et réutilise-les session après session.

→ [Contextes IA](./contextes-ia)

---

## Méthode 3 : MCP DockSky (Cursor / VS Code)

Pour une intégration native et à jour en continu :

1. **Paramètres → Accès IA** : génère un token `dk_ai_…`
2. Configure le serveur MCP (`https://api.docksky.fr/tda/mcp`, header `X-AI-Token`)
3. L'IA appelle `docksky_boot`, `docksky_load`, `get_facet_context`, etc.

Les projets en accès **NONE** sont exclus ; **WRITE** est requis pour les suppressions de facettes (si autorisées dans tes paramètres).

→ [Synapse et MCP (Cursor)](./synapse-mcp-cursor)

---

## Ce qui n'existe pas (encore)

| Fonctionnalité | État |
|----------------|------|
| Lien HTTP public vers le contexte d'un projet | Non disponible |
| Injection automatique dans Claude / ChatGPT sans MCP | Non — copier-coller ou MCP |
| Révocation d'un « lien de contexte » | N/A — révoque plutôt ton **token MCP** dans Paramètres |

:::caution
Ne configure pas d'instruction système du type « consulte mon URL DockSky » : ce mécanisme n'est pas implémenté. Utilise MCP ou le JSON copié.
:::
