# Où est la vérité ?

Quand plusieurs textes se contredisent, une seule tête de pont compte pour le **produit utilisateur** :

**[docs.docksky.fr](https://docs.docksky.fr)** — ce site (repo `DockSky-release`).

---

## Hiérarchie

| Couche | Rôle | Exemple |
|--------|------|---------|
| **Documentation (SSOT)** | Manuel, faits produit, protocoles MCP publics | Cette doc |
| **Site marketing** | Pitch, SEO, CTA — résume et **lie** ici | [docksky.fr](https://docksky.fr) |
| **Mémoire de projet** | Décisions, TRAPs, notes de *ton* chantier | Facettes dans l'app |
| **Guides techniques internes** | Deploy, scripts, Alembic | Repos API / infra (pas le manuel user) |

---

## Règle simple

1. Un fait produit change → on met à jour **cette doc** en premier.
2. Le site web et la FAQ ne font que **résumer + pointer** vers la page docs concernée.
3. Les facettes gardent la mémoire de *ton* travail ; elles ne recopient pas le manuel.

Si tu te demandes « c'est où la vérité ? » → **docs.docksky.fr**.
