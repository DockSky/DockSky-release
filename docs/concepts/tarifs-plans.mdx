# Tarifs et plans

DockSky est en **accès anticipé**. Les offres payantes (Plus, Pro) arrivent progressivement. Le **plan Free** est utilisable dès maintenant.

Détail à jour sur [docksky.fr](https://docksky.fr/#tarifs).

---

## Plans DockSky App

| Plan | Prix (cible) | Projets | Actions / mois | Stockage | MCP |
|------|--------------|---------|----------------|----------|-----|
| **Free** | 0 € | 3 actifs | 150 créations | 50 Mo | MCP TDA : `mcp:read` + `mcp:write` (100 appels/jour) |
| **Plus** | 3,90 €/mois *(bientôt)* | Illimités | 500 | 250 Mo | MCP idem Free (300 appels/jour) |
| **Pro** | 9,90 €/mois *(bientôt)* | Illimités | Illimitées | 2 Go | + scope `mcp:synapse` (`synapse_exec`, 1000 appels/jour) |
| **Équipage** | Invitation | Pro offert | Idem Pro | Idem Pro | Idem Pro |

:::info Qu'est-ce qu'une « action » ?
Une **action** = un objet **créé** ce mois-ci (tâche, entrée journal, idée, entrée facette, note knowledge). Les modifications ne comptent pas.
:::

## Équipage

Les membres invités reçoivent un code **DSK-…** à saisir **dans l'app**, à l'inscription. Il active le plan **Pro** gratuitement pendant la co-construction du produit.

Ressources : [docksky.fr/equipage](https://docksky.fr/equipage) · [Guide Équipage](https://docksky.fr/equipage/guide) · [Parcours](https://docksky.fr/equipage/parcours)

## MCP et Pilotage IA

| Capacité | Free | Pro / Équipage |
|----------|------|----------------|
| Token MCP (`dk_ai_…`) | Oui | Oui |
| Scopes | `mcp:read`, `mcp:write` | + `mcp:synapse` |
| Appels MCP / jour (plafond plan) | 100 (Free) · 300 (Plus) | 1000 (Pro) |
| Lire/écrire projets, facettes, journal | Oui | Oui |
| `synapse_exec` (commandes infra via Cursor) | Non | Oui |

Le serveur MCP expose **62 outils** au total (TDA + Synapse). Voir [Synapse et MCP](../integration-ia/synapse-mcp-cursor).

---

## Pilotage IA (Synapse) dans l'app

Tout compte **Bandeau** (Free inclus) active Synapse avec des **quotas**:

| Quota | Free Synapse | Pro Synapse |
|-------|--------------|-------------|
| Exécutions / mois | 250 | 25 000 |
| Secrets | 5 | 500 |
| Machines | 1 | 10 |

Configuration dans **Paramètres → Coffre / Machines / Journal**. L'exécution via **Cursor** (`synapse_exec`) reste réservée au **plan Pro** (scope MCP).
