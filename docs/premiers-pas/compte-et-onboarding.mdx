# Compte et onboarding

DockSky synchronise tes projets, facettes et journal sur le cloud. Un **compte gratuit** suffit pour commencer.

---

## Premier lancement

1. L'app affiche la fenêtre **Onboarding**
2. Tu saisis ton **email**, un **mot de passe** et un **nom d'utilisateur**
3. Un **code à 6 chiffres** arrive par email (vérifie les spams)
4. Tu valides le code → compte activé
5. Ta **machine** est enregistrée automatiquement (empreinte matérielle)

Sans compte validé, l'app ne se connecte pas au serveur.

Après connexion, un **premier écran** peut te proposer de choisir comment l'IA te parle (cartes de presets : partenaire, direct, etc.). Ce texte devient ton **Profil IA** : il est envoyé aux agents MCP au `docksky_boot` (`user_collab`) et placé en tête des exports JSON. Tu peux le modifier plus tard dans [Paramètres](../fonctionnalites/settings).

→ [Contextes IA — Profil IA](../integration-ia/contextes-ia#profil-ia) · [Session MCP](../integration-ia/session-mcp)

---

## Code Équipage (optionnel)

Si tu as reçu une invitation **Équipage**, saisis un code **DSK-…** lors de l'inscription. Il active le plan **Pro** sur ton compte.

Sans code : tu obtiens le plan **Free** (3 projets actifs, 150 actions/mois, 50 Mo). Voir [Tarifs et plans](../concepts/tarifs-plans).

---

## Limite de machines

Chaque compte peut enregistrer **2 machines** (ex. PC fixe + portable). Au-delà, l'app te propose de retirer une machine existante.

---

## Se reconnecter

Sur une machine déjà enregistrée, DockSky te reconnecte automatiquement (token local).

Sinon: email + mot de passe depuis la fenêtre de connexion.

---

## Mode démo (après connexion)

Le **mode démo** n'est pas un parcours sans compte. Une fois connecté, tu peux l'activer depuis le menu pour explorer l'interface avec des données d'exemple.

---

## Problèmes fréquents

| Situation | Piste |
|-----------|-------|
| Code email non reçu | Spams, attendre 2 min, bouton « Renvoyer » |
| « Machine déjà utilisée » | Limite 2 machines, retirer l'ancienne dans Paramètres |
| Mot de passe oublié | Lien **Mot de passe oublié** sur l'écran de connexion |
