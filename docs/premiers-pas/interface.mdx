# Tour de l'interface

DockSky tient dans le bandeau. Les vues s'ouvrent en fenêtres. Le bouton ⋯ les rassemble.

---

## Le Bandeau permanent

Le bandeau est **toujours visible**, quel que soit ce que tu fais. Il est ancré en haut de la fenêtre et reste accessible depuis n'importe quelle vue.

Il remplit deux rôles:
- **Capture rapide**: saisir une tâche, une idée ou un rappel sans changer de vue
- **Information permanente**: heure, notifications, Pomodoro, **Init IA**, overflow **Tout voir**

→ Voir [Bandeau permanent](../fonctionnalites/bandeau-permanent) pour le détail complet.

---

## Le menu ⋯

Les vues s'ouvrent en fenêtres, par-dessus le bandeau. Le bouton **⋯** du bandeau les rassemble. **Tout voir** les range en **5 groupes** :

### Vue d'ensemble

| Vue | Rôle |
|-----|------|
| 🏠 **Dashboard** | Vue d'accueil, stats du jour, actions en retard |
| 🔔 **Notifications** | Alertes agrégées (retards, rappels, badges) |
| ⏰ **Rappels** | Gestion des rappels horodatés |
| 📅 **Agenda** | Vue mensuelle des événements |
| 🗺️ **Roadmap** | Progression de tes projets |
| ✅ **Liste des accomplis** | Historique de tes victoires |

### Productivité

| Vue | Rôle |
|-----|------|
| 🍅 **Pomodoro** | Timer de focus avec statistiques |
| 🔁 **Routines** | Habitudes structurées et Watchdog |
| ⚡ **Exécution** | Mode une-tâche-à-la-fois |

### Organisation

| Vue | Rôle |
|-----|------|
| 📁 **Projets** | Gestion de tes projets |
| ☑️ **Tâches** | Liste unifiée de toutes tes actions |
| 📊 **Backlog** | Actions hors roadmap uniquement |
| 🧠 **Facettes** | Mémoire structurée par projet |
| 🤖 **Contextes IA** | Composition de contextes pour ton IA |
| 🗺️ **Parcours** | Timeline chronologique de ta progression |
| 📓 **Journal** | Carnet de bord de session |
| 🗑️ **Corbeille IA** | Notes de facettes supprimées, restaurables |

### Capture

| Vue | Rôle |
|-----|------|
| 💡 **Idées** | Carnet d'idées brutes |
| 🆓 **Actions libres** | File d'attente hors roadmap (raccourci bandeau) |
| 📚 **Knowledge** | Base de connaissances personnelle |

### Compte

| Vue | Rôle |
|-----|------|
| 👤 **Profil** | Informations de compte |
| 🏆 **Achievements** | Badges et gamification |
| ⚠️ **Alertes système** | Alertes techniques de l'app |
| ⚙️ **Paramètres** | Configuration de l'app |

**Paramètres**, **Pilotage IA** et **Aide** sont aussi en haut du menu ⋯, sans passer par Tout voir.

---

## Les modes d'affichage

Le badge **Modes** du bandeau propose trois présentations. Chacune met d'autres boutons devant. **Tout voir** reste disponible dans les trois.

- **Général** — navigation large : tableau de bord, notifications, roadmap, projets, idées, actions libres, knowledge, agenda
- **Dev** — session code et IA : exécution, tâches, roadmap, facettes, contextes IA, knowledge, journal, Pomodoro
- **Créa** — session idées et texte : idées, knowledge, journal

Un [module désactivé](../fonctionnalites/settings) (Pomodoro, agenda, routines, achievements) disparaît du bandeau et de Tout voir.

Un **mode assistant** (aides sous le bandeau) peut te guider la première fois. Ce n'est pas un quatrième mode de navigation.

## Co-écriture IA (ProposalReview)

Quand une IA connectée en MCP **propose** une écriture (mode `propose` / `ask`), l'app ouvre **ProposalReview** : tu lis le brouillon, tu amendes si besoin, tu confirmes. Rien n'est écrit dans tes données tant que tu n'as pas validé.

→ [Session MCP](../integration-ia/session-mcp)

## Raccourcis clavier globaux

| Raccourci | Action |
|-----------|--------|
| `Ctrl+K` | Capture Knowledge (panneau sous le bandeau) |
| `Ctrl+Shift+B` | Signaler un bug sur la vue active |
| *(configurable)* | Activer le bandeau permanent depuis n'importe quelle app |

Les raccourcis globaux fonctionnent même quand DockSky est en arrière-plan.
