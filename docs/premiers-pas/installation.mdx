# Installation

:::caution Accès anticipé
DockSky est en **accès anticipé**. Windows et Linux sont disponibles.

Il peut exister des bugs ou des comportements inattendus. C'est normal à ce stade, tes retours nous aident directement à améliorer l'application.
:::

## Ce dont tu as besoin

- Un ordinateur sous **Windows 10 / 11** ou **Linux x64** (Ubuntu 20.04+, Debian 11+ et dérivés)
- Environ **200 Mo** d'espace disque libre
- Une connexion internet pour le premier démarrage

---

## Télécharger DockSky

### Windows

**Option 1: Installateur (recommandé)**

Télécharge et lance **`DockSky-Setup-*.exe`**   l'application s'installe en quelques secondes et se met à jour automatiquement.

👉 **[Dernière version Windows   GitHub Releases](https://github.com/DockSky/DockSky-release/releases/latest)**

**Option 2: Version portable (sans installation)**

Télécharge **`DockSky-win-Portable.zip`**, extrais l'archive où tu veux, et lance `DockSky.exe` directement. Pas de mise à jour automatique.

### Linux

**Option 1: Snap (Ubuntu, en cours de publication)**

Le paquet Snap est en cours de validation sur le Snap Store. En attendant, privilégie l'AppImage ou le script ci-dessous.

Quand il sera disponible:

```bash
sudo snap install docksky
```

👉 Suivi: [DockSky sur Snap Store](https://snapcraft.io/docksky) · statut « bientôt » sur [docksky.fr/telecharger](https://docksky.fr/telecharger)

**Option 2: AppImage (toutes les distros, recommandé aujourd'hui)**

Télécharge **`DockSky.AppImage`** depuis GitHub Releases, rends-le exécutable et lance-le :

```bash
chmod +x DockSky.AppImage && ./DockSky.AppImage
```

Mise à jour automatique intégrée (Velopack).

**Option 3: Script d'installation**

```bash
curl -fsSL https://docksky.fr/install.sh | bash
```

Installe l'AppImage dans `~/.local/bin` avec raccourci menu.

👉 **[Dernière version Linux   GitHub Releases](https://github.com/DockSky/DockSky-release/releases/latest)**

## Premier lancement

Au premier démarrage, DockSky te guide dans la **création de ton compte**: email, mot de passe, vérification par code à 6 chiffres, puis enregistrement de ta machine (Windows ou Linux).

Voir le détail: [Compte et onboarding](./compte-et-onboarding).

Une fois connecté, tu peux explorer l'app normalement. Le **mode démo** (menu dédié) permet aussi de parcourir l'interface avec des données d'exemple, **après** connexion.
