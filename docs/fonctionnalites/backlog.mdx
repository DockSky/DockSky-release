# 📋 Backlog

Le **Backlog** est la vue des **tâches hors roadmap** : actions sans étape assignée (`step_id` vide), qu'elles aient un projet ou non.

:::tip
- **Tâches** (menu) = liste **unifiée** de toutes les actions (roadmap + libres)
- **Backlog** = uniquement les actions **pas encore** rattachées à une étape
- **Actions libres** = même périmètre que le Backlog, accessible aussi depuis le bandeau (🆓)
:::

:::tip
Utilise la **Roadmap** pour piloter l'avancement par projet/étape. Utilise le **Backlog** pour traiter la file d'attente hors roadmap.
:::

---

## Créer une tâche rapidement

En haut du Backlog, un **champ de création rapide** te permet d'ajouter une tâche en une ligne: 1. Tape le titre de la tâche
2. Appuie sur **Entrée** ou clique **Ajouter**

La tâche est créée instantanément dans tes actions libres. Tu peux ensuite la rattacher à un projet depuis le Backlog ou depuis la [Roadmap](./roadmap).

---

## Filtres disponibles

Le Backlog propose trois filtres combinables: | Filtre | Options |
|--------|---------|
| **Projet** | Filtrer par projet spécifique |
| **Catégorie** | Filtrer par catégorie de tâche |
| **Statut** | TODO, En cours, Terminé, etc. |

Le bouton **Réinitialiser les filtres** efface tous les filtres en un clic.

---

## Gérer les tâches depuis le Backlog

Sélectionne une tâche pour accéder aux actions disponibles:
- **Modifier**   éditer titre, priorité, deadline, estimation de temps
- **Compléter**   marquer la tâche comme DONE
- **Déplacer**   rattacher à un projet ou une étape de roadmap
- **Supprimer**   suppression douce (récupérable depuis la Corbeille)

---

## Backlog vs Tâches vs Actions libres

| Vue | Contenu |
|-----|---------|
| **Tâches** | Toutes les actions (planifiées sur roadmap + hors roadmap) |
| **Backlog** | Actions **hors roadmap** uniquement, filtrables |
| **Actions libres** | Même périmètre que le Backlog (accès rapide bandeau 🆓) |

Pour les tâches capturées rapidement et pas encore planifiées, voir aussi [Actions libres](./actions-libres).
