# ⚙️ Paramètres

La vue **Paramètres** regroupe toutes les options de configuration de DockSky. Les paramètres sont organisés en sections thématiques.

---

## Accéder aux Paramètres

**Menu Vue** → _⚙️ Paramètres_

---

## Démarrage

### Vue par défaut

Choisis la vue qui s'affiche automatiquement quand tu lances DockSky:

| Option | Recommandé si |
|--------|---------------|
| Dashboard | Tu veux un bilan rapide au démarrage |
| Roadmap | Tu passes directement au travail |
| Exécution | Tes journées sont très structurées |
| Notifications | Tu veux voir les alertes en premier |

---

## Modules actifs

Dans **Paramètres → Modules actifs**, tu peux désactiver des blocs optionnels (ils disparaissent du menu tant qu'ils sont off) :

| Module | Vues concernées |
|--------|-----------------|
| Pomodoro | Timer et stats |
| Agenda | Calendrier |
| Routines | Habitudes / Watchdog |
| Gamification | Achievements |
| Compagnon | Chien / bulles (sinon toast sur le bandeau) |

Le cœur (projets, facettes, bandeau, MCP) reste toujours là.

---

## Notifications

Configuration des notifications système et des alertes:
- **Activer / désactiver** les notifications desktop
- **Seuil d'alerte retard** — après combien de jours une action en retard génère une notification
- **Rappels automatiques** — activer ou non les rappels du Watchdog

---

## Bandeau permanent

- **Raccourci clavier global** — la touche ou combinaison pour activer le bandeau depuis n'importe quelle app
- **Position** — haut ou bas de l'écran
- **Mode toujours visible** — conserver le bandeau au-dessus de toutes les fenêtres

---

## Pomodoro

- **Durée par défaut** des sessions de travail
- **Durée des pauses** courtes et longues
- **Son d'alerte** à la fin du timer

---

## Thème et affichage

- **Thème**: Sombre / Clair / Système
- **Taille du texte**: normale, grande
- **Langue** de l'interface

---

## Intégration IA

- **Autorisation de suppression IA** (Paramètres → Intégration IA, voir [Corbeille IA](./corbeille))
- **Profil IA** — préférences de collaboration (ton, rythme) : injectées en MCP via `user_collab` au `docksky_boot`, et en tête des exports JSON
- **Init IA** — client par machine : presse-papiers (défaut) ou Cursor (deeplink)

Les écritures MCP suivent le mode **propose / ask / direct** (réglage compte + consentement de session). Quand c'est `propose` ou `ask`, tu confirmes dans **ProposalReview**. Détail : [Session MCP](../integration-ia/session-mcp).

### Accès IA (token MCP)

Section **🤖 Accès IA** — en bas de la page Paramètres :

- Génère un **token IA** (`dk_ai_…`) pour connecter Cursor ou VS Code au serveur MCP DockSky
- Quota journalier : plafond selon le plan (Free **100** · Plus **300** · Pro **1000** appels/jour)
- Validité : **30 jours** par défaut
- Le token complet n'est affiché **qu'une seule fois** à la génération — copie-le immédiatement
- **Révoquer** désactive le token actif

→ Configuration MCP: [Session MCP](../integration-ia/session-mcp) · [Synapse et MCP (Cursor)](../integration-ia/synapse-mcp-cursor)

### Pilotage IA (Synapse)

Sections disponibles pour tout compte **Bandeau** (Free inclus, quotas selon le plan):

| Section | Rôle |
|---------|------|
| **🔐 Coffre Pilotage IA** | Secrets personnels référencés par `{{NOM}}` dans les commandes, valeurs jamais affichées |
| **🖥️ Mes machines Synapse** | Profils d'exécution (slug, conteneurs autorisés) pour `synapse_exec` |
| **📋 Journal Synapse** | 30 dernières exécutions IA, stdout masqué, lecture seule |

L'exécution **`synapse_exec` via MCP** (Cursor) requiert le plan **Pro** (scope `mcp:synapse`). Voir [Tarifs et plans](../concepts/tarifs-plans).

L'app ne propose **pas** de bouton pour exécuter des commandes: l'exécution passe par l'IA (MCP) ou l'API. L'app sert à configurer et surveiller.

→ Documentation complète: [Pilotage IA (Synapse)](../integration-ia/pilotage-ia-synapse)

## Intégrations calendrier

Section **Intégrations** :

- **Google Calendar** — connexion OAuth, choix des agendas à synchroniser, option pour pousser tes événements locaux
- **iCloud** — identifiant Apple + mot de passe d'application

Un bouton **Synchroniser maintenant** force un passage. L'Agenda DockSky reste la vue locale ; le cloud est un miroir, pas un remplacement.

→ [Agenda et Rappels](./agenda-rappels)

---

## Compte

- **Déconnexion** de la session DockSky
- **Synchronisation** — forcer une resynchronisation complète avec le serveur

---

## Réinitialiser

Le bouton **Réinitialiser** en haut de la page remet tous les paramètres à leurs valeurs par défaut. L'action nécessite une confirmation.

:::note
La réinitialisation des paramètres n'affecte pas tes données (projets, tâches, facettes). Elle n'agit que sur les préférences de l'interface.
:::
