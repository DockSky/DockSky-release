# Changelog

Historique des versions de DockSky.

---

## v0.9.403+ (courant, 2026)

Version courante. Téléchargements : [docksky.fr/telecharger](https://docksky.fr/telecharger) (canal officiel). Le numéro mineur suit le compteur Git de l'app (`0.9.{commits}`).

### Aligné au code (septembre 2026)

- **Session MCP** : `docksky_boot` / `docksky_load` / `docksky_close` (aliases `dsk-boot`, `dsk-load`, `dsk-close`) — voir [Session MCP](../integration-ia/session-mcp)
- **Profil IA / `user_collab`** : préférences de collaboration injectées au `docksky_boot` (et exports JSON) — presets au premier lancement
- **Documentation SSOT** : docs.docksky.fr = tête de pont produit — voir [Où est la vérité ?](../concepts/source-de-verite)
- **Écritures IA** : modes propose / ask / direct + fenêtre **ProposalReview** dans l'app
- **Co-écriture live** : `ui_present` ouvre une vue DockSky depuis l'agent
- **ChatGPT Free** : pas de MCP custom (limite OpenAI) — copier-coller JSON en V1
- **Init IA** dans le bandeau (presse-papiers, option Cursor)
- **Intro produit** sous le bandeau (passerelle d'aides) + overflow **Tout voir**
- **Modules optionnels** : Pomodoro, Agenda, Routines, Gamification, Compagnon
- **Agenda** : sync **Google Calendar** et **iCloud**
- **Capture Knowledge** : `Ctrl+K` (panneau sous le bandeau)
- MCP : `mcp:read` + `mcp:write` dès Free ; `mcp:synapse` (`synapse_exec`) en Pro / Équipage

### Canaux

- **Windows** : **Microsoft Store uniquement** (plus d'installateur `.exe` ni de zip portable pour les utilisateurs finaux)
- **Linux** : AppImage (Velopack) + script `curl -fsSL https://docksky.fr/install.sh | bash` ; Snap en cours de publication
- Plans Free / Équipage (code **DSK-…** à l'inscription) / offres payantes à venir
- Site docksky.fr (Store-only, parcours Équipage, FAQ tarifs, page `/mcp`)

v0.9.338: Version stable Windows + Linux (mai 2026)

Version majeure: DockSky est maintenant disponible sur **Windows et Linux**. L'exécutable est renommé `DockSky` sur toutes les plateformes.

### Téléchargement (historique v0.9.338)

:::note Canaux actuels
Depuis 2026, **Windows** passe par le **Microsoft Store** uniquement. **Linux** : AppImage ou script d'installation — voir [Installation](../premiers-pas/installation).
:::

**Windows (obsolète — ne plus distribuer aux utilisateurs finaux)**
- Installateur `.exe` et zip portable GitHub (remplacés par le Store)

**Linux**
- AppImage et archives GitHub Releases (toujours valides pour Linux)

### Nouveautés

- **Version Linux disponible** (x64 - Ubuntu, Debian et dérivés)
- Mise à jour automatique (Velopack) sur Windows et Linux
- Agenda et rappels
- Gamification, badges, XP, niveaux de rareté (Common / Rare / Legendary)
- Routines, création, types, modes, déclencheurs, templates
- Roadmap et Quick Wins
- Pomodoro flottant (widget toujours visible)
- Vues **Tâches** et **Backlog** (actions hors roadmap)
- **Inbox** (notifications agrégées : retards, rappels, badges)
- Compagnon virtuel Bretton Spaniel (animations physiques, bulles de dialogue)
- Mode démo intégré (exploration avec données d'exemple, **après** connexion)
- Onboarding initial guidé (compte + vérification email)
