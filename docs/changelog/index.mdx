# Changelog

Historique des versions de DockSky.

---

v0.9.339: Correctif build (mai 2026)

Version corrective technique.

### Correction

- Correction des URIs de ressources internes (Avalonia) suite au renommage de l'exécutable en `DockSky`

---

v0.9.338: Version stable Windows + Linux (mai 2026)

Version majeure: DockSky est maintenant disponible sur **Windows et Linux**. L'exécutable est renommé `DockSky` sur toutes les plateformes.

### Téléchargement

**Windows**
- [DockSky-Setup-0.9.338.exe](https://github.com/DockSky/DockSky-release/releases/latest/download/DockSky-Setup-0.9.338.exe): Installateur Windows (recommandé)
- [DockSky-win-Portable.zip](https://github.com/DockSky/DockSky-release/releases/latest/download/DockSky-win-Portable.zip): Version portable Windows

**Linux**
- [DockSky-linux-x64-0.9.338.tar.gz](https://github.com/DockSky/DockSky-release/releases/latest/download/DockSky-linux-x64-0.9.338.tar.gz): Archive Linux x64
- [docksky_0.9.338_amd64.deb](https://github.com/DockSky/DockSky-release/releases/latest/download/docksky_0.9.338_amd64.deb): Paquet Debian/Ubuntu

### Nouveautés

- **Version Linux disponible** (x64 - Ubuntu, Debian et dérivés)
- Mise à jour automatique (Velopack) sur Windows et Linux
- Agenda et rappels
- Gamification, badges, XP, niveaux de rareté (Common / Rare / Legendary)
- Routines, création, types, modes, déclencheurs, templates
- Roadmap et Quick Wins
- Pomodoro flottant (widget toujours visible)
- Vue Kanban des tâches
- Inbox (capture rapide depuis n'importe où)
- Compagnon virtuel Bretton Spaniel (animations physiques, bulles de dialogue)
- Mode démo intégré (exploration sans compte)
- Onboarding initial guidé

v0.9.289: Accès anticipé (mai 2026)

Première version publique de DockSky, disponible en accès anticipé (Windows uniquement).

### Ce qui était disponible

- Gestion de projets → actions → étapes
- Facettes (mémoire structurée par projet)
- Contextes IA (composition et export de contexte pour ton IA)
- Knowledge Manager
- Bandeau permanent (capture rapide)
- Notifications et actions en retard
- Actions libres (tâches non planifiées)
